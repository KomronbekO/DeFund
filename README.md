# DeFund — A Hybrid Crowdfunding DApp

[![CI](https://github.com/KomronbekO/DeFund-A-Hybrid-Crowdfunding-DApp/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/KomronbekO/DeFund-A-Hybrid-Crowdfunding-DApp/actions/workflows/ci.yml)

[![Tests](https://img.shields.io/badge/tests-44%20passing-brightgreen)](#testing)

CN6035 (Mobile and Distributed Systems) — Task 1 coursework.

DeFund is a Kickstarter-style decentralised application. Creators publish funding campaigns; backers pledge ETH through MetaMask; the smart contract releases funds to the creator if the goal is met by the deadline, or lets backers refund their pledges otherwise. The system is intentionally hybrid: an on-chain Solidity contract is the source of truth, an Express backend with an event indexer mirrors state into a SQLite cache, an Express API gateway sits in front of the backend, and a Next.js (SSR) React frontend renders everything.

> **For the design rationale, data flows, and tradeoffs, see [`ARCHITECTURE.md`](./ARCHITECTURE.md).**
>
> **For the academic write-up, see [`docs/report.md`](./docs/report.md).**

## Stack

| Layer          | Technology                                                                             |
| -------------- | -------------------------------------------------------------------------------------- |
| Smart contract | Solidity 0.8.24, Hardhat, OpenZeppelin (ReentrancyGuard)                               |
| Backend API    | Node 20, Express, TypeScript, Prisma over SQLite, ethers v6, pino                      |
| Indexer        | Built into the backend; poll loop using `queryFilter`, single-flight queue             |
| Object storage | Local disk (default) **or** Pinata IPFS                                                |
| API gateway    | Express, http-proxy-middleware, express-rate-limit, pino-http, SIWE                    |
| Frontend       | Next.js 14 (App Router), TypeScript, Tailwind, wagmi v2, RainbowKit, viem              |
| Tooling        | ESLint, Prettier, Solhint, Husky, lint-staged, Jest, supertest, Vitest, GitHub Actions |

## Quickstart (local dev, 4 terminals)

You'll need:

- **Node.js 20** — `nvm use` honours [`.nvmrc`](./.nvmrc)
- **MetaMask** browser extension (or any injected EVM wallet)
- About 5 minutes

### Step 1 — Install everything (once)

```bash
git clone <this-repo> dapp-coursework
cd dapp-coursework
nvm use
npm install
npm --workspace backend run prisma:generate
```

`npm install` installs all four workspace packages (root `package.json` lists them as workspaces). `prisma:generate` creates the typed Prisma client used by the backend.

### Step 2 — Wire up environment files

```bash
cp contracts/.env.example contracts/.env
cp backend/.env.example   backend/.env
cp gateway/.env.example   gateway/.env
cp frontend/.env.example  frontend/.env.local
```

Defaults are pre-tuned for local development — you don't need to edit anything to run on a local Hardhat node. (The Hardhat first-deploy address is deterministic, so it's already filled in.)

### Step 3 — Initialise the SQLite database (once)

```bash
cd backend && npx prisma db push --skip-generate --accept-data-loss && cd ..
```

This creates `backend/prisma/dev.db` and applies the schema. Re-run any time you want to wipe local cache state.

### Step 4 — Start the four services

Open four terminals (or use `tmux`/`screen`):

| Terminal | Command                              | Port | What it does                               |
| -------- | ------------------------------------ | ---- | ------------------------------------------ |
| 1        | `npm --workspace contracts run node` | 8545 | Local Ethereum chain (chain id 31337)      |
| 2        | `npm --workspace backend run dev`    | 4001 | REST API + on-chain event indexer          |
| 3        | `npm --workspace gateway run dev`    | 4000 | API gateway (rate-limit, auth, proxy)      |
| 4        | `npm --workspace frontend run dev`   | 3000 | Next.js (set `PORT=3001` if 3000 is taken) |

Wait for terminal 1 to print "Started HTTP and WebSocket JSON-RPC server", then in a 5th terminal (or after closing terminal 1's foreground process if you backgrounded it):

```bash
npm --workspace contracts run deploy:local
```

This deploys `Crowdfunding.sol` to the local node, writes the contract address + ABI to `contracts/deployments/localhost.json`, and prints lines you can paste into `backend/.env` if you want to override the default. (You usually don't — Hardhat is deterministic.)

Optionally seed a demo campaign:

```bash
npm --workspace contracts run seed   # see contracts/scripts/seed.ts
```

### Step 5 — Connect your wallet

1. Open <http://localhost:3000> (or 3001 if you remapped the port).
2. **Add the local network to MetaMask** (one-time):
   - MetaMask → network selector → "Add a custom network"
   - Network name: `Hardhat Local`
   - RPC URL: `http://127.0.0.1:8545`
   - Chain ID: `31337`
   - Currency: `ETH`
3. **Import a Hardhat dev account** (one-time):
   - MetaMask → account avatar → "Add account or hardware wallet" → "Import account"
   - Paste any private key Terminal 1 printed at startup
   - The imported account holds 10,000 fake ETH on this chain
4. **Connect** — click the wallet button on the site, approve in MetaMask.

### Step 6 — Try it

| Action                                            | Steps                                                                                                                                             |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Create a campaign**                             | Click `New campaign`, fill form, optionally upload an image, submit, MetaMask confirm. The page redirects to home; new card appears within ~1.5s. |
| **Pledge**                                        | Open a campaign, type an amount, click Pledge, MetaMask confirm. Sidebar total updates within ~1.5s — no manual refresh.                          |
| **Claim** (creator, after deadline, goal met)     | Open the campaign as the creator account → green Claim button → MetaMask confirm.                                                                 |
| **Refund** (backer, after deadline, goal NOT met) | Open the campaign as a backer → amber Refund button → MetaMask confirm.                                                                           |
| **Test the deadline path quickly**                | Use Hardhat's time travel (see [Troubleshooting → testing time-dependent flows](#testing-time-dependent-flows)).                                  |

## Configuration

Every workspace has an `.env.example` with annotated keys. Defaults are sufficient for local dev.

### `contracts/.env`

```bash
SEPOLIA_RPC_URL=                # Required for deploy:sepolia
PRIVATE_KEY=                    # Deployer wallet private key (testnet only!)
ETHERSCAN_API_KEY=              # Required for verify:sepolia
REPORT_GAS=false                # Set true to print a gas report after `npm test`
```

### `backend/.env`

```bash
PORT=4001
NODE_ENV=development
DATABASE_URL="file:./dev.db"

CHAIN_RPC_URL=http://127.0.0.1:8545
CHAIN_NETWORK=localhost         # Selects which contracts/deployments/<x>.json to load
CONTRACT_ADDRESS=               # Optional override; otherwise read from deployments file
DEPLOY_BLOCK=0                  # Indexer starts replaying from this block

PINATA_JWT=                     # Optional — leave empty to use local-disk storage
PUBLIC_BASE_URL=http://localhost:4000  # Where uploaded files are reachable
```

### `gateway/.env`

```bash
PORT=4000
BACKEND_URL=http://127.0.0.1:4001
FRONTEND_ORIGIN=http://localhost:3000  # CORS origin
RATE_LIMIT_WINDOW_MS=60000
RATE_LIMIT_MAX=60
REQUIRE_AUTH_ON_UPLOADS=false   # Toggle SIWE auth on POST /uploads
```

### `frontend/.env.local`

```bash
NEXT_PUBLIC_GATEWAY_URL=http://localhost:4000
NEXT_PUBLIC_CHAIN_ID=31337                    # 31337 (Hardhat) or 11155111 (Sepolia)
NEXT_PUBLIC_CONTRACT_ADDRESS=0x5FbDB2315678afecb367f032d93F642f64180aa3
NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID=         # Optional — only needed for WalletConnect
```

## Testing

```bash
npm test                                      # Run all 44 tests across all workspaces
npm --workspace contracts test                # 18 contract tests
npm --workspace contracts run coverage        # Solidity-coverage report → contracts/coverage/
npm --workspace backend test                  # 12 REST + indexer tests (Jest + supertest)
npm --workspace gateway test                  # 4 gateway tests (Jest + supertest + stub upstream)
npm --workspace frontend test                 # 18 unit tests (Vitest + jsdom)
```

Lint and format:

```bash
npm run lint                                  # ESLint + Solhint everywhere
npm run format:check                          # Prettier
npm run format                                # Prettier --write
```
